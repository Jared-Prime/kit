# mixin: skills

### skills

#### `codebase-memory`

Use `codebase-memory` for semantic lookups prior to using `rg` for source file exploration.

#### `commit-message`

Use `commit-message` when a user intends to submit a patch to a project.

#### `guided-review`

Use `guided-review` when a user requires a pragmatic walkthrough of a changeset.

#### `introspection`

Use `introspection` to validate sandbox configuration, settings, and tooling.
